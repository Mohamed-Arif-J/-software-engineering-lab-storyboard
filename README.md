# Software Engineering Lab Storyboard

## Student Hostel Management System

This repository documents the planning, modelling, development progress, and challenges encountered while working on the **Student Hostel Management System** as part of the Software Engineering Laboratory.

### Course Alignment

The storyboard is organized around the practical activities supported by the laboratory syllabus:

- Software modelling tools
- Software Requirements Specification (SRS)
- Entity Relationship (ER) modelling
- Use Case Diagram
- Data Flow Diagram (DFD)
- Activity Diagram
- Object Diagram
- Sequence Diagram
- Small web-based application prototype
- Testing and documentation

## GitHub Project Board

Progress is tracked using a GitHub Projects Kanban board with three columns:

- **To Do** – planned work
- **In Progress** – currently active work
- **Done** – completed and reviewed work

## Repository Structure

```text
requirements/   Requirements documentation
 diagrams/      System modelling diagrams
progress/       Progress, timeline, and problem records
application/    Prototype planning and implementation notes
```

## Project Objective

To design and prototype a system that helps hostel administrators manage students, rooms, attendance, complaints, fees, and related hostel activities in an organized manner.

## Status

The project is being developed incrementally. Completed activities will be moved to the **Done** column only after they are actually completed and supported with suitable evidence.
